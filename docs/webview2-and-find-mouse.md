# 鼠标增强升级方案

**状态：已接入。** 「鼠标增强」配置窗口从本地加载 Vue 设置页。浏览器可预览同一套页面，独立 Avalonia 预览项目可直接播放原生聚光灯。

「寻找鼠标」支持双击 Ctrl 和摇晃鼠标，触发后同时遮暗所有显示器，聚光灯随指针跨屏移动。设置页通过侧边栏组织各项功能。现有搜索入口、设置数据和窗口拖动启停命令继续使用。

## 设置页

| 侧边栏 | 设置内容 |
| --- | --- |
| 窗口拖动 | 功能开关、Alt／Win 修饰键、右键调整大小、抑制 Alt 窗口菜单、排除窗口、排除修饰键 |
| 滚轮音量 | 功能开关、Alt／Win 修饰键 |
| 桌面与任务栏 | 双击桌面切换图标、双击任务栏显示桌面 |
| 寻找鼠标 | 功能开关、触发方式、外观参数和预览效果 |

- 保留 MioKit 单实例设置窗口。页面跟随宿主的浅色和深色主题，支持键盘导航，加载失败时在原生窗口中显示错误。
- 开关与有效字段修改即时保存并生效。窗口拖动与滚轮音量共用一个修饰键，两页同步显示当前值。窗口拖动关闭时，仍可在「滚轮音量」页调整修饰键。
- 两个排除列表各自维护草稿，切换侧栏时保留编辑内容，点击「应用排除列表」后一起生效。支持手动输入进程名或窗口标题关键字，也支持按住准星拖到目标窗口。原生覆盖层高亮目标，松开后将进程文件名加入对应草稿。应用时去掉空行和行首尾空白，拖选添加时忽略大小写去重。

## 寻找鼠标

### 触发方式

- 首次安装和升级后总开关默认关闭。打开总开关时，双击 Ctrl 默认可用，摇晃鼠标可单独启用。设置窗口关闭后，全局手势继续运行。
- **双击 Ctrl**。左 Ctrl 和右 Ctrl 均可使用，一次手势由同一侧 Ctrl 的两次完整短按组成。每次按住不超过 250 毫秒，两次松开相隔不超过 500 毫秒。组合键、长按、按键重复和模拟输入不触发。
- **摇晃鼠标**。在 650 毫秒内统计主方向上的有效反转。每次反转须移动至少 32 个物理像素，累计达到设定阈值时触发。按住鼠标按钮期间暂停识别，避免拖动时误触。

### 聚光灯与外观

触发后，所有屏幕同时变暗，指针周围保留透亮的圆形区域并显示彩色光晕。光圈随指针移动，跨屏时根据各屏幕的 DPI 绘制。鼠标操作穿透遮罩，前台窗口保持焦点。点击鼠标、按 Esc、播放结束或停用功能时清理遮罩。「预览效果」在总开关关闭时也可使用。

| 选项 | 默认值 | 取值或含义 |
| --- | --- | --- |
| 聚光灯颜色 | `#8b5cf6` | `#RRGGBB` 格式 |
| 聚光灯直径 | 200 逻辑像素 | 48–640 逻辑像素 |
| 遮罩强度 | 74% | 0–100% |
| 光晕强度 | 19% | 0–100% |
| 动画时长 | 400 毫秒 | 0–2000 毫秒，淡入和淡出各使用一次 |
| 停留时长 | 800 毫秒 | 100–5000 毫秒，从完全显示后开始计时 |
| 摇晃阈值 | 7 次 | 3–12 次有效反转 |

## 实现与兼容性

1. **迁移设置窗口。** 使用宿主共享的 `MioKit.Webview2` 1.3.1 承载 `plugin/vue-ui` 构建到 `plugin/ui/dist` 的 Vue 页面。插件包包含页面资源，支持离线加载。浏览器预览使用同一套页面资源，真实桥接在 MioKit 宿主中验证。
2. **接通设置与原生拾取。** C# 桥接负责读取设置、更新字段、应用排除列表、开始或取消拾取、预览聚光灯。仅接受来自设置页专用本地来源的消息，校验字段和值，并将失败结果返回页面。现有 EAV 属性及其标识继续使用，寻找鼠标配置存入独立 EAV 属性。保留原有窗口命令的实时启停行为和两种排除列表的作用范围。
3. **接通全局手势与聚光灯。** 在现有 `MouseEnhanceService` 中复用宿主的键鼠监听，让手势识别独立于窗口拖动开关，并保持原有输入处理结果。每块显示器使用一个原生透明覆盖窗口，渲染调度到 UI 线程。停用功能或停止插件时，清除识别状态、撤销排队的显示请求并关闭覆盖窗口。
4. **验证安装与升级。** 检查插件包内的本地资源和入口，使用旧版设置数据验证升级路径，再在真实 MioKit 宿主中完成下列验收。

## 验收标准

- [ ] **升级兼容。** 原有开关、修饰键、两个排除列表、搜索入口和窗口拖动启停命令均可正常使用。新装和升级后，「寻找鼠标」均默认关闭。
- [ ] **设置交互。** 验证侧边栏、浅色和深色主题、键盘导航、修饰键同步、即时保存与重新打开后的持久化。验证两个列表的草稿隔离、跨侧栏保留、拖选、高亮和显式应用。
- [ ] **手势边界。** 自动覆盖双击 Ctrl 的时间边界、左右 Ctrl、组合键、长按、模拟输入，以及摇晃的时间、距离、阈值和拖动误触。窗口拖动关闭后，两种寻找鼠标手势仍可运行。
- [ ] **多屏和穿透。** 在包含负坐标、不同缩放比例的屏幕布局中验证所有屏幕同时变暗、跨屏光圈对齐、点击穿透和焦点保持。
- [ ] **生命周期。** 验证关闭设置页后全局手势仍可用，预览可在总开关关闭时运行，点击、Esc、超时、停用和重启时正确清理覆盖窗口。覆盖停用时已有显示请求排队的情况。
- [ ] **打包与回归。** 安装插件包后，验证设置页可离线打开，缺少 WebView2 Runtime 时有明确错误提示。重新运行 Release 构建和现有桌面图标命中回归，并在宿主中验证滚轮音量、窗口拖动、双击桌面及任务栏手势。
